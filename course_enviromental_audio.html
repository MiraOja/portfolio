Focus

  • Environmental audio as scalable systems
  • Wwise patterns: events, states, switches, RTPCs
  • Unreal integration that stays debuggable
  • Profiling-driven iteration
View on EXPA Email for updates

Who it’s for

Sound designers who want to learn implementation workflows and build maintainable audio systems using Wwise + Unreal Engine.

Syllabus

Five modules, one environment.

Module 1 — Advanced Footstep Systems

Surface types, speed RTPCs, variation, profiler debugging.

Module 2 — River Audio Systems

Layering, distance behavior, coherence, spatial logic.

Module 3 — Forest Ambience Systems

Beds vs micro-events, density control, long-session fatigue.

Module 4 — Interior & Ruined House Audio

Occlusion, blending, leakage, reverb as context.

Module 5 — Cave Audio Systems

Isolation, transitions, sparse design, scale through reverb.

Bonus — Downloadable Reference Project

Reference implementation + notes for architecture and profiling habits.
